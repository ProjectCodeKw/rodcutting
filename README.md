# Rod Cutting Algorithm Comparison

This Streamlit web application visually demonstrates and compares the performance of two approaches to the classic Rod Cutting problem:

- **Brute Force:** A straightforward, recursive approach that explores all possible ways to cut the rod.
- **Dynamic Programming (Bottom-Up):** An efficient approach that solves subproblems and builds up to the optimal solution, avoiding redundant calculations.

## Overview

The Rod Cutting problem aims to find the most profitable way to cut a rod of a given length into smaller pieces, where each piece of a certain length has an associated price. This application allows you to:

- **Analyze Pre-generated Data:** Compare the running times of the Brute Force and Bottom-Up Dynamic Programming algorithms for different rod lengths using randomly generated price data.
- **Test Custom Input:** Input your own rod length and price array to see the optimal cutting solution and compare the performance of the two algorithms in real-time.
- **Visualize Performance:** View tables and interactive plots illustrating the time taken by each algorithm for varying rod lengths.
- **Understand the Recursion:** Observe the recursion tree generated by the Brute Force approach for a given input.
- **See the Optimal Solution:** Visualize the optimal cuts on the rod and the corresponding optimal total price calculated by the Bottom-Up approach.

## Features

- **Clear Visual Comparison:** Side-by-side analysis of the Bottom-Up and Brute Force algorithms.
- **Interactive Rod Length Selection:** Use a slider to choose the rod length for custom testing.
- **Custom Price Input:** Enter your own array of prices for different rod lengths.
- **Real-time Performance Measurement:** See the execution time of both algorithms for your custom input.
- **Dynamic Plots:** Visualize the running time comparison for pre-generated data.
- **Recursion Tree Visualization:** Understand the branching nature of the Brute Force approach.
- **Optimal Cutting Solution Display:** See the calculated optimal cuts and the maximum revenue.
- **Intuitive User Interface:** Built with Streamlit for easy interaction.

## How to Use

### Bottom-Up Vs Brute Force Analysis

1.  Navigate to the "Bottom-Up Vs Brute Force Analysis" tab.
2.  **About:** Read a brief introduction to the Rod Cutting problem and the purpose of this application.
3.  **Generating Data:** Understand how the pre-generated data was created for the analysis. A sample of the random price data used is displayed in a table.
4.  **Running Time (ms): Bottom Up Vs Brute Force:**
    - View a table comparing the running times (in milliseconds) of the Bottom-Up and Brute Force algorithms for different rod lengths (n).
    - See the theoretical time complexities of both algorithms (`O(n^2)` for Bottom-Up and `O(2^n)` for Brute Force).
    - Observe a line plot visualizing the running time of both algorithms against the rod length.
    - View another line plot showing the time difference between the Brute Force and Bottom-Up approaches on a logarithmic scale, highlighting the exponential growth of the Brute Force algorithm.

### Try New Input

1.  Navigate to the "Try New Input" tab.
2.  **Select Rod Length:** Use the slider to choose the length of the rod you want to cut (from 1 to 7).
3.  **Randomly Generated Data:** Observe a randomly generated array of prices for rod lengths up to your selected length.
4.  **Or you can use your own data:** Enter your own array of prices in the text input field (e.g., `[1, 5, 8, 9]`). If you provide your own data, the rod length will be determined by the length of your price array.
5.  **Recursion Tree:** A visualization of the recursion tree generated by the Brute Force algorithm for your chosen input will be displayed. This illustrates the large number of redundant subproblems explored by the brute-force method.
6.  **CUT THE ROD!!:** Click the "CUT THE ROD!!" button to run both algorithms on your selected input.
7.  **Running Time Analysis:** A table will appear showing the running time (in milliseconds) for both the Bottom-Up and Brute Force algorithms for your input. The winner (the algorithm with the faster execution time) will be highlighted.
8.  **Rod Cutting Solution:**
    - A table will display the optimal price and the cut position for each subproblem (rod length from 1 to n) calculated by the Bottom-Up Dynamic Programming approach.
    - The optimal total price for the rod will be shown.
    - A horizontal bar chart will visualize the optimal cuts on the rod. Green dashed lines indicate the positions where the rod should be cut to achieve the maximum revenue.

## Code Explanation

### Algorithms

- **`rod_cutting(p: list, n: int)`:** Implements the Bottom-Up Dynamic Programming approach to solve the Rod Cutting problem.
    - `p`: A list of prices where `p[i-1]` is the price of a rod of length `i`.
    - `n`: The total length of the rod.
    - It returns the maximum revenue (`q`), an array `r` storing the optimal revenue for each rod length up to `n`, and an array `s` storing the optimal first cut for each rod length.

- **`brute_force(p: list, n: int)`:** Implements the recursive Brute Force approach to solve the Rod Cutting problem.
    - `p`: A list of prices.
    - `n`: The total length of the rod.
    - It explores all possible cut combinations and returns the maximum revenue.

### Data Generation

- **`generate_data()`:** This function (commented out in the main execution) was used to generate random price data for different rod lengths (5, 10, 15, 20, 25) and record the execution times of both algorithms in text files within the `data/` directory.

### Data Visualization

- **`plot1()`:** Generates a line plot comparing the running times of the Bottom-Up and Brute Force algorithms for different rod lengths using the pre-generated data. It also displays the data in a table.
- **`plot2()`:** Generates a line plot showing the time difference between the Brute Force and Bottom-Up algorithms on a logarithmic scale, further emphasizing the performance disparity as the rod length increases.

### Recursion Tree

- **`rod_cutting_recursion(prices, n, depth=0, parent=None)`:** A recursive function used to generate the recursion tree for the Brute Force algorithm using the `graphviz` library. Each node in the tree represents a subproblem (remaining rod length).

### Solution Reconstruction

- **`reconstruct_cuts(s, n)`:** This function takes the `s` array (containing the optimal first cut for each length) returned by the `rod_cutting` function and reconstructs the sequence of cuts needed to achieve the optimal revenue.

### Test Input Function

- **`test_input()`:** This function handles the interactive "Try New Input" tab, allowing users to select a rod length, input custom prices, visualize the recursion tree, run both algorithms, compare their running times, and see the optimal cutting solution.

## Performance Analysis

The application clearly demonstrates the significant difference in time complexity between the two approaches:

- **Bottom-Up Dynamic Programming:** Has a time complexity of O(n^2), making it efficient for larger rod lengths.
- **Brute Force:** Has a time complexity of O(2^n), resulting in exponential growth of execution time as the rod length increases, making it impractical for larger inputs.

The plots and real-time tests highlight how the Bottom-Up approach remains efficient while the Brute Force approach becomes increasingly slow.
